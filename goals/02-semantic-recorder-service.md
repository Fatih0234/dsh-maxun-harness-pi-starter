# Goal 2 — semantic Maxun Recorder Draft service

## Goal

Replace the one-shot hidden Maxun LLM construction boundary with a server-side semantic draft capability that the Harness agent can steer incrementally while Maxun retains selector ownership.

## Success criteria

- [x] First-class draft identity exists independent of React Recorder state.
- [x] Server operations expose repeated-list candidates as opaque IDs.
- [x] Selected list can expose field candidates with stable field IDs, samples, attribute/tag metadata, and validation coverage.
- [x] Semantic field include/exclude/rename operations do not require the model to author CSS/XPath.
- [x] Pagination can be auto-detected and actually tested.
- [x] Preview returns rows plus structured diagnostics.
- [x] Validation can run current-page and multi-page checks.
- [x] Draft compiles deterministically to the same native Maxun `scrapeList` workflow/runtime.
- [x] Harness tools use the semantic API and the one-shot hidden Maxun LLM path is no longer required for normal construction.
- [x] Existing Maxun Recorder behavior remains working.
